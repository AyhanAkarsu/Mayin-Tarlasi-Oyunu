# Mayın Tarlası Oyunu

A small console Minesweeper game written in C. The board is 8×8 with eight mines.

## Build

With GCC:

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o minesweeper
```

Run it with `./minesweeper` and enter row and column numbers when prompted.

## Status

Learning project. Input validation and portability improvements are planned.
